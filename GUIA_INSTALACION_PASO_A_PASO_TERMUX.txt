FASE 1: LLEGADA AL RESTAURANTE Y CONEXION FISICA
================================================================================
1. Saluda al equipo y ubica la zona de caja.
2. Conecta la pantalla táctil de la caja a su toma de corriente y enciéndela.
3. Conecta el cable USB de la impresora térmica a la pantalla de la caja.
4. Conecta el cable del cajón monedero (RJ11) directamente a la impresora.
5. Pide la clave del Wi-Fi del restaurante y conecta la pantalla a la red Wi-Fi.

================================================================================
FASE 2: FIJAR LA IP ESTATICA (FIJA) EN LA PANTALLA ANDROID
================================================================================
POR QUE SE HACE:
Si el router del restaurante se reinicia por la noche o hay un bajon de luz,
el router le cambiaria la direccion a la pantalla (ej. de .50 a .14) y los 
celulares de los meseros no sabrian a donde enviar los pedidos. Fijando la IP,
la pantalla SIEMPRE tendra exactamente la misma direccion para siempre.

COMO FIJARLA EN ANDROID (Toma 1 minuto):
1. Ve a: Ajustes de Android > Internet y redes > Wi-Fi.
2. Toca el engranaje (⚙) o manten presionada la red Wi-Fi del restaurante a la que te conectaste.
3. Toca el lapiz de editar o busca "Opciones avanzadas".
4. Busca la opcion "Ajustes de IP" (por defecto estara en "DHCP").
5. Cambia "DHCP" por "ESTATICA".
6. Te pedira llenar estos campos:
   - Direccion IP: Mira la que tiene asignada actualmente (ej. 192.168.1.15).
     Cambia SOLO el ultimo numero por un 50 (ejemplo: 192.168.1.50).
     (Si la red era 192.168.0.X, pones 192.168.0.50).
     *ANOTA ESTA IP: ESTA SERA LA IP DEL RESTAURANTE PARA SIEMPRE*.
   - Puerta de enlace: La misma que tenia (normalmente 192.168.1.1 o 192.168.0.1).
   - Longitud de prefijo de red: Escribe 24 (equivale a 255.255.255.0).
   - DNS 1: Escribe 8.8.8.8
   - DNS 2: Escribe 8.8.4.4
7. Dale a GUARDAR.
8. Abre Chrome en la pantalla y busca cualquier pagina para confirmar que navega bien.

================================================================================
FASE 3: INSTALAR LAS 2 APKS Y QUITAR RESTRICCIONES DE BATERIA
================================================================================
1. Conecta la memoria USB a la pantalla Android con el adaptador OTG.
2. Abre la app "Archivos" o "Descargas" de Android, entra a la USB e instala:
   - 1ro: com.termux_118.apk
   - 2do: com.termux.boot_7.apk
3. Abre la app "Termux:Boot" UNA SOLA VEZ (se abrira en blanco o se cerrara sola, es normal, es para que Android active el permiso de auto-arranque).
4. QUITAR AHORRO DE ENERGIA (Para que Android nunca mate el servidor):
   - Ve a: Ajustes de Android > Aplicaciones > Ver todas.
   - Entra a "Termux" > Bateria (o Uso de bateria) > Ponlo en "SIN RESTRICCIONES" (o "No optimizar").
   - Haz lo mismo con "Termux:Boot" > Bateria > "SIN RESTRICCIONES".
   - Si la pantalla tiene seccion de "Inicio automatico" o "Autostart", dale permiso a ambas.

================================================================================
FASE 4: CONFIGURAR TERMUX (MOTOR LINUX Y BASE DE DATOS)
================================================================================
Abre la app TERMUX (icono de pantalla negra) y ejecuta paso por paso:

1. Permisos basicos:
termux-setup-storage
(Saldra ventana pidiendo permiso de almacenamiento, dale "PERMITIR")

termux-wake-lock
(Evita que el procesador se suspenda)

2. Instalar motor Linux (Python, Postgres, Git, Node):
pkg update -y && pkg install -y python python-pip postgresql git nodejs clang make libjpeg-turbo libffi
(Espera unos minutos a que descargue todo).

3. Configurar base de datos interna:
initdb -D $PREFIX/var/lib/postgresql
pg_ctl -D $PREFIX/var/lib/postgresql -l $PREFIX/var/log/postgres.log start
createuser -s restaurante
createdb -O restaurante restaurante
psql -U restaurante -d restaurante -c "ALTER USER restaurante WITH PASSWORD 'restaurante_dev';"

4. Descargar el codigo de Mr. Burger:
Si la pantalla tiene internet:
cd ~
git clone https://github.com/novapos003-debug/Mr.Burger.git mrburger
cd mrburger

(Si no hay internet y lo trajiste en la USB a la carpeta Download de Android:
cd ~
cp -r /sdcard/Download/mrburger ~/mrburger
cd ~/mrburger)

5. Inyectar recetas y catalogo real de Mr. Burger a la base de datos:
cd ~/mrburger
psql -U restaurante -d restaurante -f database/init/01_schema.sql
psql -U restaurante -d restaurante -f database/init/02_seeds.sql
psql -U restaurante -d restaurante -f database/init/03_migracion_arquitectura_e_insumos.sql

6. Instalar librerias de Python y servidor web:
pip install fastapi uvicorn[standard] sqlalchemy pydantic pydantic-settings python-multipart python-jose[cryptography] passlib[bcrypt] psycopg2-binary httpx websockets
npm install -g serve

FASE 5: AUTOMATIZACION TOTAL (CERO COMANDOS PARA EL CLIENTE)
================================================================================
Copia y pega este bloque completo de una sola vez en Termux y da Enter:

cat << 'EOF' > ~/iniciar.sh
#!/data/data/com.termux/files/usr/bin/bash
termux-wake-lock

# 1. PostgreSQL
if ! pg_isready -q; then
    pg_ctl -D $PREFIX/var/lib/postgresql start
fi

# 2. Backend
if ! pgrep -f "uvicorn app.main:app" > /dev/null; then
    cd ~/mrburger/backend
    export DATABASE_URL="postgresql://restaurante:restaurante_dev@localhost:5432/restaurante"
    export SECRET_KEY="ymKGPH7kaMDwp4CJZluFvgU3BRcAnbrj"
    nohup uvicorn app.main:app --host 0.0.0.0 --port 8000 > ~/backend.log 2>&1 &
fi

# 3. Frontend
if ! pgrep -f "serve -s dist" > /dev/null; then
    cd ~/mrburger/frontend
    nohup serve -s dist -l 5173 --cors > ~/frontend.log 2>&1 &
fi
EOF

chmod +x ~/iniciar.sh
chmod +x ~/mrburger/actualizar_termux.sh
ln -sf ~/mrburger/actualizar_termux.sh ~/actualizar.sh

# Vincular al encendido de la pantalla
mkdir -p ~/.termux/boot
ln -sf ~/iniciar.sh ~/.termux/boot/01-mrburger.sh

# Vincular por si abren Termux manualmente
echo "~/iniciar.sh" >> ~/.bashrc

# Encender los servicios ahora mismo:
~/iniciar.sh

FASE 6: CREAR EL ICONO DE LA CAJA Y PROBAR LA IMPRESORA
================================================================================
1. En la misma pantalla Android abre GOOGLE CHROME.
2. Escribe en la barra: http://localhost:5173
3. Toca los 3 puntos arriba a la derecha de Chrome y selecciona:
   "Instalar aplicacion" (o "Agregar a pantalla principal").
4. Vuelve al escritorio de Android: Veras el icono oficial con el logo "Mr. Burger".
5. Abre la app desde ese icono y entra con el usuario de Caja o Admin.
6. Ve al modulo de Caja / Configuracion de Impresora:
   - Toca "Conectar Impresora USB" y dale "Permitir siempre a esta app".
   - Haz clic en "Imprimir Prueba": la impresora debe emitir la tirilla y abrir el cajon.

FASE 7: CONECTAR LA TABLET DE COCINA (KDS)
================================================================================
1. Conecta la tablet de cocina a la red Wi-Fi del restaurante.
2. Abre Google Chrome en la tablet y escribe la IP estatica que fijaste en el Paso 2:
   Ejemplo: http://192.168.1.50:5173
3. Toca los 3 puntos de Chrome > "Instalar aplicacion" (o "Agregar a pantalla principal").
4. Inicia sesion con el rol de COCINA.
5. Subele el volumen al maximo a la tablet para que se escuche el "Ding-Dong".

================================================================================
FASE 8: CONECTAR LOS 4 CELULARES DE LOS MESEROS
================================================================================
En cada uno de los celulares de los meseros:
1. Conectalos al Wi-Fi del restaurante (¡desactivar datos moviles para asegurar que use el Wi-Fi!).
2. Abre Google Chrome y escribe la IP fijada:
   Ejemplo: http://192.168.1.50:5173
3. Toca los 3 puntos de Chrome > "Instalar aplicacion" (o "Agregar a pantalla principal").
4. Veras que les queda el icono "Mr. Burger" como una app nativa de celular.
5. Inicia sesion con el rol de MESERO.

PRO TIP DE EMERGENCIA (SI NO ALCANZAN A DIGITAR INSUMOS EL PRIMER DIA):
Si un mesero intenta pedir una hamburguesa y la pantalla dice "Falta Pan" o "Falta Carne",
es porque el stock esta en 0 y el sistema protege de vender sin existencias cargadas.
Para permitir que vendan sin trabas mientras terminan de digitar las compras:
Entras al panel Admin > Configuracion > "Politica ante stock insuficiente"
y la cambias a "ADVERTIR Y PERMITIR". Asi podran vender todo libremente.

FASE 12: ¿CÓMO ACTUALIZAR EL LOGO O EL SISTEMA MAÑANA DESDE TU CASA / PC?
================================================================================
Si el cliente te envía el logo definitivo mañana (o quieres hacer un cambio):

1. EN TU PC:
   - Guarda el nuevo logo reemplazando el archivo: frontend/public/logo.png
   - Recompila y sube los cambios a GitHub:
     cd "frontend" && npm run build
     git add .
     git commit -m "Actualizar logo oficial Mr. Burger"
     git push origin main

2. EN LA CAJA (EN EL RESTAURANTE):
   - Opción A (Vía Remota con AnyDesk sin moverte de tu casa):
     Abres AnyDesk en tu PC, te conectas a la pantalla de la Caja, abres Termux y ejecutas:
     ~/actualizar.sh
   - Opción B (Si estás en el restaurante o el dueño lo hace en 5 segundos):
     Abren Termux en la pantalla de la caja (con Wi-Fi conectado) y escriben:
     ~/actualizar.sh

3. ¿Y LOS TELÉFONOS DE MESEROS Y TABLET DE COCINA?:
   - ¡NO TIENES QUE TOCAR NINGUNO DE LOS 5 DISPOSITIVOS!
   - Gracias a la arquitectura PWA (Progressive Web App), todos los teléfonos
     y tablets detectan la nueva versión automáticamente por Wi-Fi.
   - Les saldrá un aviso "¡Nueva versión disponible! [Actualizar]" o simplemente
     al recargar la pantalla, y el nuevo logo aparecerá en todos al instante.
